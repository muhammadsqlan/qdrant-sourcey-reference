The API reference is generated directly from the unchanged specification. It covers collections, points, search, indexes, aliases, snapshots, distributed operations, quotas, service endpoints, and beta endpoints.

The guide's examples are schema-checked. They have not been executed against a live Qdrant server. Generated examples may need collection-specific values. The development snapshot can differ from a released server.

Upstream's specification introduction retains legacy search examples using `top`. The query guide uses the current `query` endpoint and `limit`; the original input remains intact for reproducibility.

This independent reference is not endorsed by Qdrant. Source attribution and the upstream license are preserved.
