# Dedicated Qdrant documentation host

Live reference: https://qdrant.muhammadsqlan.com/

This revision hosts the independent reference at the root of a dedicated
subdomain. The parent personal homepage remains unchanged. Qdrant has not
endorsed this reference. Bounty acceptance and payment are unconfirmed.

The generated bytes are in `site/`. The root repository retains the unchanged
upstream source, guides, CSS, exact dependency versions, license notices, and
validator. The new evidence and receipt in this directory apply to this build.

From the repository root, use a new output directory for reproduction:

```sh
SOURCEY_SITE_URL=https://qdrant.muhammadsqlan.com SOURCEY_BASE_URL= \
  npx sourcey build --config docs/sourcey.config.ts -o site-subdomain-new
RUNX_INPUT_BUILD_DIR=site-subdomain-new RUNX_INPUT_BASE_URL= node validation/validate.mjs
runx skill validation -i build_dir=site-subdomain-new -i base_url= -R receipts-subdomain-new -j
runx verify --receipt <new-receipt-path> --allow-local-development-signatures --json
```

The last command is for the explicitly disclosed local-development signature.
It is not independent notarization or proof of live hosting. Live checks are
recorded separately in `live-verification.json` and the maintainer report.
