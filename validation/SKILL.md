---
name: qdrant-sourcey-validation
description: Validate a pinned Qdrant API documentation build without modifying it.
---

Run the deterministic validator against a prebuilt Sourcey site. It verifies the
source hash, API coverage, local links and anchors, search entries, licensing,
source attribution, assets, and landing-page size. It reads local files only.
The receipt attests to these checks; it does not attest to hosting or payment.
